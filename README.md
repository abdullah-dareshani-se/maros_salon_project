## 🌸 About the Project

Maro's Beauty Salon is a premium salon experience designed for beauty-conscious clients who value elegance, hygiene, and personalized care. The website highlights the salon’s premium services, professional atmosphere, and customer support.

This landing page includes:
- Elegant hero section with salon branding
- About us area
- Premium service gallery
- Contact and WhatsApp details
- Instagram and email links
- Address and business hours
- Mobile responsive layout
